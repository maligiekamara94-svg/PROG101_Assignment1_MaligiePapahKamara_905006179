# CleanSalone: Community Waste Reporting and Collection Tracker

**Course:** PROG101 Principles of Programming Logic and Design
**Assignment:** Assignment 1, Designing Logical Solutions for Sierra Leone Community Challenges
**Student:** Maligie Papah Kamara (905006179)
**Institution:** Limkokwing University of Creative Technology, Sierra Leone Campus

## Problem
Waste in Freetown is not collected, tracked or prioritised in a coordinated way. Waste in drains causes flooding and spreads disease. Residents have no simple way to report dump sites, and crews are often sent by habit rather than urgency.

## Solution
CleanSalone is a **logical design** (no source code) for a system that lets residents report dump sites, ranks each report as HIGH, MEDIUM or LOW, and assigns the nearest crew with free capacity. If all crews are full, reports are queued and served by priority when a crew becomes free.

## Modules
1. Main Program (menu loop)
2. Report Intake (input and validation)
3. Priority Checker
4. Crew Assignment
5. Status Update
6. Statistics Report

The design is intended to be released under an OSI-approved open licence (for example Apache 2.0) so councils, students and developers in Sierra Leone can reuse, translate and improve it.
